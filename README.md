# miniature-garbanzo website

This is a tiny static website for the miniature-garbanzo repository. It includes:

- index.html — landing page
- css/styles.css — lightweight styles with a dark theme
- js/script.js — simple interactions (theme toggle, contact form simulation, gallery toast)

How to use

1. Serve the repository (for local preview) with any static server, for example:

   npx http-server -c-1

2. Or open index.html directly in a browser.

Notes

- The contact form is a client-side placeholder and does not submit to a backend.
- Feel free to modify or expand the showcase tiles into real demos.
